# T04 双人内容审核记录

审核规则：开发者与家长分别对每个字的10项逐项填写“是/否”。任一项未检查或为“否”，该字审核字段保持`false`，G2保持失败，`childTrialEnabled=false`。

审核项：

1. 简体字形规范、清晰、字体一致；
2. 女声普通话发音和声调准确；
3. 字义适合5岁且无错误简化；
4. 图片主旨唯一、无歧义；
5. 词语真实、常用、适龄；
6. 句子自然、口语化；
7. 每题正确答案唯一；
8. 干扰项不存在第二正确答案；
9. 音频可离线播放、无截断；
10. JSON引用与实际资源一致。
