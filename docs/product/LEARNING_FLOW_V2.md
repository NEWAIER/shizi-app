# 识字 APP V2.0 学习流程

## 自动流程

```text
ENTER_STEP → PLAY_PROMPT → PLAY_CONTENT → HOLD → SAVE_PROGRESS → ADVANCE
```

单字读音结束停留约 0.8–1.0 秒，儿童释义停留约 1.0–1.2 秒，词语停留约 0.5 秒，例句停留约 1.0–1.5 秒。音频失败时停留在当前步骤并提供重听，不自动跳过。

## 交互规则

每道题进入即自动播放提示；点击答案立即判断。第一次错误给温和提示并重播，第二次错误突出正确答案、播放字音并进入教学反馈。正确反馈后约 800ms 自动下一题。无提交、确认或手动下一题按钮。

## 可中断性

重听不重复写入进度；暂停、退出、时间限制和返回均可恢复；快速点击不能叠加播放。自动推进前先持久化当前步骤，持久化失败不得发放奖励。
