# V2.0 页面验收清单

- 360×640、360×800、390×844、412×915、430×932 均不横向溢出。
- 1.2 倍系统字体下正文、按钮和汉字不裁切。
- 学习三阶段自动播放、自动推进；音频失败可重听且不跳过。
- 练习进入自动播放；每题一次主要点击；错误反馈可恢复。
- 退出后可以继续；进度先保存再推进；奖励事件幂等。
- 字卡为五列网格，卡片仅展示汉字和掌握状态；单击播放，长按详情。
- 我的页面展示头像、等级、星星、进度、连续学习和徽章墙。
- 正常、空、错误、加载和恢复状态均有可理解反馈。
- 不新增敏感权限，不破坏现有五字学习记录，不依赖 Emoji 正式图标。
