# 识字 APP V2.0 儿童 UX 流程冻结

## 主流程

```text
启动
  ↓ 自动定位今天内容
学习首页（最多 1 次点击）
  ↓
认识字：大字 + 拼音 + 图片 + 自动读音
  ↓ 自动
了解意思：图片 + 儿童解释 + 角色陪伴
  ↓ 自动
组词例句：2 个词语 + 1 个例句 + 自动播放
  ↓ 自动
挑战：听音找字 / 看字找图 / 找相同字
  ↓
星星奖励 → 回到学习首页
```

## 交互规则

- 前三步由系统自动播放和推进，孩子只需看和听。
- 音频播放失败时保留明显的重播按钮，不阻塞页面。
- 每个挑战题点击选项即可反馈，不设置“提交”按钮。
- 答错使用鼓励、提示和再次尝试，不出现失败页或红色惩罚。
- 任意中断后恢复到当前字和当前步骤，不要求孩子重新选择入口。
- 成人设置和数据查看通过家长入口隔离，不出现在儿童主路径。

## 页面边界

学习页只承载今天的字；挑战页只承载复习和阶段挑战；字卡页只承载已遇到的字；我的页只承载头像、星星、等级、徽章和成长记录。

## 冻结验收

首次打开到开始学习不超过一次儿童点击；一个字的前三步不要求儿童点击下一步；每个状态都有声音、视觉和返回路径。
