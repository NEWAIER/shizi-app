# 字宝宝星球视觉方向 V1

## 设计气质

儿童是在认识字宝宝、收集星星、帮助角色找朋友。固定陪伴角色负责欢迎、讲解、倾听、鼓励、庆祝、再试一次和休息，不只是装饰。

## 颜色令牌

主背景 `#FFF6E8`，学习主色 `#38B7A5`，辅助蓝 `#64A9FF`，奖励黄 `#FFD75E`，挑战紫 `#8C7CF6`，活力珊瑚 `#FF8B72`，正确绿 `#68C985`，错误提示 `#FFD1C9`，正文 `#2F3B45`。

每页只使用一个主色；错误不使用大面积红色；学习以青绿和蓝色为主，挑战以紫色为主，我的页面以星空紫和奖励黄为主。

## 尺寸与动效

目标汉字 96–128sp，拼音 24–30sp，标题 24–28sp，词语 22–26sp，例句 18–22sp，按钮文字 20–22sp。主要按钮高度 64–72dp，普通点击区域至少 56dp，圆角 20–28dp。页面切换 200–300ms，反馈 300–500ms，庆祝 1–2 秒；不使用持续闪烁。

## 图标与字体

正式图标使用统一矢量图标系统，不以 Emoji 代替。汉字使用清晰规范字形，不使用卡通变形体或书法体。所有页面通过 `ShiziTypography` 与主题令牌统一控制。
