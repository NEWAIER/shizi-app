# 识字 APP V2.0 儿童体验规范

状态：PR-FE-00 / 冻结

## 1. 核心用户

唯一核心用户是约 4 岁、识字量较少、阅读复杂说明困难、点击控制能力有限的儿童。家长、教师和成人用户只属于辅助角色，不作为儿童主流程的设计对象。

## 2. 当前体验问题

- 首页同时展示学习、复习、阶段测试等多个任务，儿童需要先理解入口再做选择。
- 学习步骤依赖播放和继续按钮，儿童必须理解“下一步”概念。
- 练习存在提交/确认感，容易形成考试体验。
- 旧页面文字密度高，关键信息与辅助信息竞争注意力。
- 字卡详情信息过多，不适合快速图鉴浏览。
- 默认 Material 卡片和 Emoji 图标缺少统一的陪伴角色与成长世界观。

## 3. 产品原则

### 少点击

打开 APP 后 1 次以内进入今日学习。儿童不需要阅读说明、选择学习入口、点击下一步或点击确认。

### 自动陪伴

学习固定为：认识字 → 了解意思 → 组词例句 → 测试。前三步默认自动播放并自动推进，儿童主要负责看和听。

### 游戏化而不是考试化

不使用考试、排名、扣分、红色大面积错误反馈或提交按钮。使用星星、徽章、角色、鼓励和成长反馈。

## 4. 信息架构

底部保留四个入口：

| 入口 | 儿童含义 |
| --- | --- |
| 学习 | 今天认识一个新朋友 |
| 挑战 | 老朋友复习与阶段挑战 |
| 字卡 | 汉字图鉴 |
| 我的星球 | 头像、等级、星星、徽章和成长记录 |

学习、练习和结果页隐藏底部导航，避免误触。家长入口只能通过成人验证进入，不出现在儿童核心任务卡中。

## 5. 页面规范

### Home V2

打开后第一眼看到固定陪伴角色和“今天认识一个新朋友”。首页只保留一个主学习入口；若存在未完成课程，入口文案为“继续认识”。复习数量和成长信息只能作为辅助提示，不能形成第二、第三张任务卡。

### Learn V2

中央展示超大汉字，下方展示拼音、辅助图片和角色气泡。进入步骤后自动播放提示音和内容音频，音频结束后短暂停留并自动进入下一步。顶部只保留轻量进度点和休息/返回能力，儿童不需要理解复杂状态。

### Practice V2

只保留听音选字、看字选图、找相同字。点击答案立即判断；第一次错误温和提示并重播，第二次错误展示正确答案并教学。正确反馈后自动进入下一题，不显示提交、确认或手动下一题。

### Learned V2

使用固定五列网格。默认卡片只展示汉字和掌握状态。单击卡片停止当前音频、播放汉字音，再播放一个常用词语；长按进入详情，详情页再展示拼音、释义、三个词语、例句和下次复习时间。

### Profile V2

页面命名为“我的星球”，展示头像、昵称、当前等级、星星能量、距离下一等级、学习进度、连续学习天数、徽章墙和已解锁装饰。未解锁内容可以预览，但不能影响儿童主学习流程。

## 6. 非目标

本轮不增加拼音四选一、强制拼音考试、排行榜、好友、账号、商城、抽奖、广告、联网语音、复杂家长运营功能，也不激活 30 字内容包。
