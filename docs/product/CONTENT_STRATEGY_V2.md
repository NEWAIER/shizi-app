# 识字 APP V2.0 内容战略冻结

## 内容四层

| 层 | 责任 | 发布要求 |
|---|---|---|
| 基础汉字库 | 汉字、拼音、部首、笔画、字频、来源 | 来源、许可证、快照指纹可追溯 |
| 儿童学习内容包 | 儿童释义、词语、例句、图片和音频需求、学习目标 | 儿童语言和家长审核通过 |
| 学习引擎 | 新字、复习、掌握、阶段挑战、间隔复习 | 规则版本化，不能由内容文本隐式改变 |
| 儿童体验层 | 字宝宝、星星、头像、等级、徽章、动画和反馈 | 遵守儿童 UX 与无考试压力原则 |

## 内容生产原则

基础数据可以复用成熟公开数据，但不能直接展示给儿童；儿童内容必须经过加工；体验层通过稳定 `characterId` 关联三层数据。每次来源、儿童文案或体验规则变化都生成新版本，不覆盖已发布包。

## 内容生命周期

```text
DRAFT → TEXT_REVIEWED → MEDIA_REVIEWED → PARENT_REVIEWED → ACTIVE
```

未达到 `ACTIVE` 的内容只能用于本地候选包联调，不得加入 active catalog。当前 30 字包继续作为兼容基线，不代表未来规模目标；50 字家庭测试包必须在审核流程和工具链完成后再启动。

## 阶段边界

当前只完成架构和工具链，不启动 30/50/100 字内容生产，不批量生成图片或音频。正式扩充前必须先通过基础库、儿童内容模型、生产工具和家庭测试验收。
