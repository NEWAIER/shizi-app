# 识字 APP V2.0 儿童体验规格冻结

状态：V2.0 / PR-FE-00 冻结

## 核心用户

唯一核心用户是约 4 岁、识字量较少、不能阅读复杂说明、点击控制能力有限的儿童。所有页面优先保证“看得懂、点得到、等得住、错了也愿意继续”。

## 产品边界

底部入口固定为“学习、挑战、字卡、我的”。学习流程采用“认识字 → 了解意思 → 词语与例句 → 立即测试”四段式。首版只保留听音选字、看字选图、找相同的字三类题型。

本轮不新增复杂题型、排行榜、好友、账号、积分商城、抽奖、广告、联网语音和复杂家长运营功能；30 字内容包待儿童体验验证通过后恢复。

## 体验原则

- 学习页自动播放提示和内容，音频结束后自动推进；儿童只在需要选择答案或重听时点击。
- 正确反馈温和、短暂、可理解；错误不扣分，第二次错误进入教学反馈。
- 学习、练习、结果页隐藏儿童底部导航，避免误触和中断。
- 家长入口必须保留成人验证，入口不参与儿童主流程。
- 不使用 Emoji 作为正式图标，不使用占位图片冒充正式资源。

## 验收基线

打开 App 后 0–1 次点击进入今日生字；教学三阶段正常情况下 0 次点击；每道题 1 次主要点击；正确后约 800ms 自动进入下一题；退出后可以恢复进度；奖励只在持久化成功且事件唯一时发放。

## 非目标

本阶段不修改现有五字内容、学习记录、复习调度和后端算法，不激活 30 字包，不引入新的敏感权限。
