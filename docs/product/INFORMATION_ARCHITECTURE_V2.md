# 识字 APP V2.0 信息架构

## 儿童主导航

| 入口 | 作用 |
| --- | --- |
| 学习 | 直接创建或继续今日生字 |
| 挑战 | 今日复习与阶段测试 |
| 字卡 | 已学习汉字五列图鉴，点击播放，长按进入详情 |
| 我的 | 头像、等级、星星能量、学习进度、徽章墙 |

学习、练习、结果页不显示底部导航。家长入口从头像长按或页面角落进入，并继续使用成人验证。

## 路由原则

App 启动后解析未完成会话：新会话进入学习，待复习会话进入练习，完成会话进入结果或学习首页。返回行为明确：儿童学习流程返回首页，字卡详情返回图鉴，家长页面返回家长入口。

## 页面层级

```text
学习
  今日生字 → 认识字 → 了解意思 → 词语例句 → 立即测试 → 结果
挑战
  今日复习 / 阶段测试 → 结果
字卡
  五列图鉴 → 字卡详情
我的
  成长首页 → 头像/装饰预览、徽章墙
```
