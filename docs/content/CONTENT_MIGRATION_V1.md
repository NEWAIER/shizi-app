# 内容迁移与扩展规则 V1

## 现有 1.0.0 包

当前 `content/v1/content.json` 是已经审核完成的运行包，继续由 `legacy-five-v1` 提供。它没有 `layers` 字段时，按 legacy 包处理，不回填猜测的来源信息。

## 新包流程

1. 导入 Foundation 快照，规范化 Unicode、拼音、声调和 ID。
2. 生成 Child Content 工作单；编辑只填写儿童可见字段和媒体需求。
3. 生成 Experience 编排；每道题引用稳定 option ID，不复制基础字典字段。
4. 编译为运行包，写入 `layers` 三层版本和 `contentVersion`。
5. 运行文本、结构、资源、许可证和 manifest 校验。
6. 完成家长/儿童可用性审核后，才把 pack 标记为 active。

## 禁止事项

- 不把开源仓库文件直接复制到 `app/src/main/assets` 作为儿童展示内容。
- 不在数据库中保存会随基础数据更新而变化的释义文本。
- 不复用旧包的媒体路径覆盖新媒体。
- 不因“有拼音和字形”就把条目视为可学习。
- 不把 1000 字一次性塞入 APK；按课程包或按需下载策略拆包，仍需离线可用的已安装包。

## 兼容策略

旧记录按 `contentVersion` 加载旧包；新包只要保留稳定 `characterId`，可以继续统计同字学习历史。删除或改变儿童语义的条目必须使用新 ID 或显式迁移表，不能悄悄复用旧 ID。
